# Dolev24.github.io

The older address of AquaPlay IPTV's public pages, kept working for TVs that still use it. The main site is now https://aquaplayiptv.github.io/. No app code lives here.

- `aquaplay-iptv/pair.html` — the page a phone opens from the QR code on a TV to send it a playlist
- `aquaplay-iptv/help.html` — AquaPlay's settings explained, opened from the app
- `aquaplay-iptv/features.html` — what is Free and what is Premium
- `aquaplay-iptv/privacy.html` — the privacy policy
- `aquaplay-iptv/test/` — a demo playlist and guide of public sample streams
- `premium.json` — a small switch the app reads to know which TVs Premium is on for

Served at https://dolev24.github.io/aquaplay-iptv/
