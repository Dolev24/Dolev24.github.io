# Dolev24.github.io

Public pages for AquaPlay IPTV. No app code lives here.

- `aquaplay-iptv/pair.html` — the page a phone opens from the QR code on a TV to send it a playlist
- `aquaplay-iptv/privacy.html` — the privacy policy
- `aquaplay-iptv/test/` — a demo playlist and guide of public sample streams

Served at https://dolev24.github.io/aquaplay-iptv/
